# 문학 서바이벌 제작소

문학작품을 바탕으로 캐릭터, 몬스터, 무기, 아이템, 강화 카드를 노드로 정하고 서바이벌 게임을 만드는 수업 도구입니다. 노드 보기와 PPT 보기를 전환하고, 게임을 미리 보거나 독립적인 HTML로 저장할 수 있습니다.

학생들은 각 종류의 도트 예시를 고르거나 32×32 그림판에서 직접 그릴 수 있습니다. 캐릭터는 선택적으로 텍스트 모델을 이용해 도트 디자인을 생성할 수 있습니다.

## Windows에서 실행

Node.js가 설치된 환경에서 `제작소_실행.cmd`를 실행한 다음 `http://127.0.0.1:8768/`에 접속합니다. 서버는 로컬 컴퓨터에서만 접속할 수 있습니다. API 없이도 예시 그림, 도트 그림판, 게임 생성 기능을 쓸 수 있습니다.

AI 캐릭터 생성에는 OpenRouter API 키가 필요합니다. 실행한 터미널의 `OPENROUTER_API_KEY` 환경변수에 키를 설정한 뒤 `node character-server.cjs`를 실행하세요. 이 프로젝트는 기존 환경과의 호환을 위해 `OPENRAOUTER_API_KEY` 이름도 인식합니다. 키는 소스 파일에 넣지 마세요.

캐릭터의 AI 생성은 브라우저별 성공 3회로 제한됩니다. 서버 재시작 후에도 제한이 유지되도록 서버 폴더에 기록되며 이 파일은 Git에서 제외됩니다. 브라우저 데이터 삭제 또는 다른 브라우저 사용으로 이 제한을 우회할 수 있습니다. 서버에 AI 사용 권한이 있는 경우 요금이 발생할 수 있습니다.

## 배포용 파일

`prepare-deploy.cjs`는 `deploy/`에 웹 경로용 HTML과 서버 코드를 생성합니다. 포함된 `literary-survival.service`와 `literary-survival-proxy.conf`는 기존 Apache/systemd 환경에 맞춘 예시이므로 다른 환경에서는 경로, 포트, 비밀키 보관 방식과 접근 제어를 확인한 후 수정해야 합니다. 배포용 서버에는 전역 일일 AI 요청 상한이 있습니다. 키와 사용 기록은 저장소에 포함하지 않습니다.
